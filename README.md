# Task 28 – Simple Percentage Analysis

## Objective
Calculate percentage contribution by product category using Excel.

## Tools Used
- Microsoft Excel

## Work Completed
- Analyzed category-wise sales.
- Calculated total sales using SUMIF.
- Calculated percentage contribution.
- Created bar and pie charts.
- Verified that percentages add up to 100%.

## Formula
Contribution % = (Category Sales / Grand Total Sales) × 100

## Outcome
Learned how percentage analysis helps understand category contributions in business reporting.
